# Octane v1.0.0

Octane v1.0.0 delivers the qualified browser-only Windows installer lab and the importable Ubuntu 24.04 WSL appliance.

## Download and assemble

Download all three binary assets from the release:

1. Extract `Octane-v1.0.0-runtime.zip` into an empty directory.
2. Place `octane-ubuntu.tar` at `appliance/octane-ubuntu.tar` under that directory.
3. Place `octane-wine-image.tar.zst` at `images/octane-wine-image.tar.zst`.
4. Compare lengths and SHA-256 values with `v1.0.0-release-assets.json`.
5. Run `./Install-Octane.ps1 -PackageRoot $PWD -PlanOnly` in Windows PowerShell 7.
6. Run `./Install-Octane.ps1 -PackageRoot $PWD` only after the plan passes.

The package intentionally keeps the WSL rootfs and Docker image separate. It does not ship a populated Docker data root.

## Boundaries

The result applies only to the exact retained Octane installer and locked environment. The minimal native Win32 WebView2 probe remains white. The custom Wine visible-region patch remains a maintenance condition. Stock Wine, arbitrary Windows/Tauri applications, Windows domain identity, certificates, mapped shares, and another installer are not qualified by this release.

No target source, target rebuild, Docker Desktop, RDP client, Podman, Proton, CrossOver, Windows VM, host GPU, broad host mount, privileged container, host networking, Docker socket mount, or WebView2 `--no-sandbox` is required.
